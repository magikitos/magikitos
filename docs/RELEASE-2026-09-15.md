## Local environment incident

The macOS pointer file is readable and valid, but DDEV reports input/output
errors. Docker's own daemon API times out and its VM log contains I/O failures
for multiple containers. This is separate from the repository extraction.
The static Node preview continues working without Docker.
The mount's clean 503 handling is verified on production and native macOS PHP.
DDEV still emits the old reader's warning and is not reflecting the current
host code; its response must not be described as repaired.

Restarting Docker affects other projects and requires the owner's approval.
No volume deletion, database import, Docker reset or broad cleanup is authorized
by this release. Local DDEV availability must not be claimed until rechecked.
